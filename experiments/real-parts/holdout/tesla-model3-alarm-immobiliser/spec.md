# spec: Vehicle alarm system and immobiliser of the Tesla Model 3

## Product Type
Anti-theft system of a battery-electric passenger car (Tesla Model 3): vehicle alarm system and immobiliser.

## Function
- Immobiliser: prevents normal operation of the vehicle without authorisation
- Alarm: signals an attempted intrusion or tampering

## Main Parts
- Immobiliser function in the vehicle electronics
- Alarm system with intrusion detection and alarm signalling

## Technology
Integrated in the vehicle's electrical/electronic architecture.
