# spec: LPG injector rail, VALTEK type 30, 4 cylinders, 3 ohm

## Product Type
Gas injector rail for a 4-cylinder engine with LPG installation.

## Function
- Injects gaseous LPG into the intake of each cylinder

## Main Parts
- Rail with 4 injectors (VALTEK type 30)
- Injector coils 3 ohm
- Calibration nozzles (not included)

## Technology
Electromagnetic gas injectors, LPG fuel system component.
